# Метки циклов

`cycle_labels.csv` создаётся веб-интерфейсом (вкладка «Разметка») или функцией `sd.dataset.save_label`. Формат:

| колонка | смысл |
|---|---|
| video | `video_id` (папка__имя), например `курение__sm_3` |
| tid | id трека на момент разметки (информативно — при смене модели он меняется) |
| peak_t | момент пика цикла (середина паузы у рта), с |
| cx, cy | положение рта в кадре (пикселей) — вместе с peak_t однозначно определяет цикл |
| label | `smoke` (затяжка) · `drink` · `phone` · `eat` · `touch_face` · `other_neg` · `ignore` · `unsure` |
| source | `manual` / `weak` |
| note, labeler, ts | комментарий, кто разметил, когда |

Метка сопоставляется циклу по (video, |peak_t − peak_t'| ≤ 1 с, положение ≤ 150 px), поэтому переживает смену порогов автомата.
`ignore` и `unsure` в обучение не берутся. Двое разметчиков должны независимо разметить 3–4 одинаковых клипа и сравнить (руководство §9.2).
