Шрифты интерфейса лежат здесь, чтобы он работал без интернета и без внешних сетевых запросов.

Geologica (кириллица и латиница, переменная насыщенность 300–700) — основной шрифт интерфейса.
  Автор: Geologica Project Authors. Лицензия SIL Open Font License 1.1. Источник: https://fonts.google.com/specimen/Geologica
IBM Plex Mono (начертания 400 и 500, кириллица и латиница) — для номеров камер, времени, клавиш и ключей параметров.
  Автор: IBM Corp. Лицензия SIL Open Font License 1.1. Источник: https://fonts.google.com/specimen/IBM+Plex+Mono

Файлы — подмножества woff2 (cyrillic и latin) с Google Fonts без изменений. Текст лицензии SIL OFL 1.1: https://openfontlicense.org
Шрифты свободно распространяются вместе с программой; при замене шрифта правится только css/fonts.css.
