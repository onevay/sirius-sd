# Детекция курения по видео

Локальный детектор курения по видео. Находит человека, отслеживает «рука ко рту», собирает циклы и превращает их в события по регламенту. Всё считается на своей машине: видео не уходят в облако.

## Что умеет

- Детекция и трекинг людей.
- Поза и признаки жеста: расстояние «запястье–рот», автомат циклов.
- Проверка предмета на кропе кисть–рот, VideoMAE/X-CLIP, VLM через локальный Ollama.
- События по правилам: 2 цикла за 20 с или цикл + прямой признак; склейка ≤ 15 с; разных людей не склеиваем.
- Dev Studio (`sd ui`) — интерфейс разработчика: валидация с PDF-отчётом и анализом слабых мест по кэшу, разметка с версиями, признаки, обучение и диагностика классификатора фоновыми задачами, выпуск через ворота качества ([docs/DEV_STUDIO.md](docs/DEV_STUDIO.md)).
- Мониторинг камер и тревоги для оператора.
- API платформы (`sd serve`) — вход и роли, тревоги и решения с историей, камеры, разбор видео, доступ к функциям разработчика; БД с миграциями (SQLite / PostgreSQL) ([docs/API.md](docs/API.md)).
- Веб-интерфейс (`sd serve` → `/app/`) — экраны оператора и разработчика на этом API: обзор, тревоги, проверка, карта, отчёты, разбор видео, эксперименты, конструктор, разметка, администрирование; зелёная палитра, шрифты Geologica и IBM Plex Mono, без внешних запросов ([docs/WEB_UI.md](docs/WEB_UI.md)).
- Перенос моделей на другое устройство через `.sdsolver.zip`.

## Как это работает

Видео → поза и трекинг → признаки `d_t` «запястье–рот» → автомат циклов → признаки предмета и видеомоделей → классификатор цикла → события по регламенту → Event F1.

## Быстрый старт

```bash
# 1. Окружение
python scripts/bootstrap.py --dev --cpu-torch

# 2. Проверка
./sd.sh doctor        # Windows: sd.cmd doctor

# 3. Прогон на папке с клипами
python -m sd.run --input clips/ --profile mvp --out preds.csv --render out_videos/

# 4. Веб-интерфейс
./sd.sh ui            # Windows: sd.cmd ui
```

Интерфейс откроется на `http://localhost:8501`.

## Окружение

Python 3.13, `.venv`, CPU-сборка torch, ultralytics, OpenVINO, ONNX Runtime, rtmlib, transformers, LightGBM, Streamlit. Проект оптимизирован под CPU и OpenVINO, чтобы работать без NVIDIA.

Тесты: `./sd.sh test` — 323 юнит-теста.

## Приватность и лицензии

Обработка полностью локальная, телеметрия Ultralytics и HF выключена. Записи с объекта нельзя загружать в облачные сервисы без письменного разрешения владельца.
